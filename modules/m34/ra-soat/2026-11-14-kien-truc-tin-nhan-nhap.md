# Tin nháp báo trước gói kiến trúc (D-m34-079) · 14/11/2026

Toàn tự gửi. Gửi xong báo phiên m34 "đã báo" để giao coder gói `kien-truc` (`wp/kien-truc.md`).

**Tài:**
> Tài ơi, anh báo trước nghen: test kiến trúc ranh giới module bên mình đang đỏ, phần lớn vì mấy file test VNPAY với cổng thanh toán Giờ Vàng gọi chéo vô ruột module khác. Mai mốt anh cho sửa lại mấy file test đó cho đúng ranh giới, chỉ đổi cách test gọi, không đổi mã chạy, số ca giữ nguyên. Em đang sửa dở mấy file đó thì nói anh một tiếng hen, để khỏi đụng nhau. Chi tiết anh để trong file.

**Phúc:**
> Phúc ơi, anh báo trước nè: test kiến trúc ranh giới module đang đỏ, có 2 file test vòng đời SKU bên catalog với 1 file test cổng thanh toán Giờ Vàng dính vô. Anh cho sửa lại phần test cho đúng ranh giới, không đụng mã chạy của em. Em đang sửa dở mấy file đó thì báo anh nha. Chi tiết anh để trong file.

Tệp gửi kèm (nếu cần): `modules/m34/wp/kien-truc.md` (mục Brief 2–3 liệt kê đúng tệp test).
